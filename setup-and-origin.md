# Setup Instructions and Origin

## Setting the ND-Adapter as a persistent instruction

The ND-Adapter prompts work in any AI system that accepts custom instructions. When a user asks how to make it apply automatically:

**Claude (claude.ai / Claude app):** Settings → Profile → personal preferences, or add it to a Project's custom instructions. Paste the short-form or long-form prompt.

**Microsoft Copilot:**
- Web (copilot.microsoft.com): menu/sidebar → Settings → Custom instructions or Personalization → paste the ND-Adapter text → save.
- Windows built-in Copilot: menu (top right) → Settings → Custom instructions → paste into the response-style field → save.
- Mobile app: profile icon/menu → Settings → Custom instructions → paste → save.

**ChatGPT:** Settings → Personalization → Custom instructions → paste into "How would you like ChatGPT to respond?"

Note: menu locations change over time. If the steps don't match what the user sees, tell them to look for "Custom instructions", "Personalization", or "Response style" in settings.

## Origin and transparency

The ND-Adapter was created by the author from lived experience through a human-led, AI-supported process. The concept, structure, categories, A/B test design, and reasoning came from lived experience of ND communication needs; AI (Copilot) was used as an editor to tighten language and formatting. Mark remained the conceptual lead and final human-in-the-loop reviewer.

Core design principle: **the adaptation burden sits with the AI system, not the ND user.** The tool changes the interface, not the person. Specialised vocabulary and authentic communication style are preserved, never "corrected".

When sharing the tool in professional or community contexts, include this transparency note — it builds trust and models good AI practice.
